# Rooftop race routes

The race registry holds three routes with the same controls and a shared finish rule. Each route starts at the existing park origin, then sends the player into a separate rooftop pocket so the base parkour fixture remains a safe training area.

- **Skyline Sprint** uses a stair-step opener, a sprint rail, a five-metre tower, a narrow bridge, a low slide gate, and a final high ledge. Its rhythm alternates quick horizontal bursts with two vertical climbs.
- **Switchback Run** uses a long vault spine, a right-angle wall, a raised return lane, a two-platform gap, a tall shimmy wall, and a landing roof. It asks for repeated direction changes and a ledge shift before the finish.
- **Helix Heights** wraps east, north, and west around a climbing spiral. The route uses angled platforms, a high rail, a controlled drop, and a final elevated pad so the player can trade height for speed.

A route finishes when the player enters the glowing finish ring. The HUD publishes the selected title, subtitle, elapsed seconds, and finish state. Choosing a route from the title screen or pause panel restarts the world with the corresponding deterministic registry entry.
